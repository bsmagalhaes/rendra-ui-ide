Funcionalidades

Tudo o que você usa com agentes de IA, numa janela só

O Rendra IDE lê os arquivos que o Claude Code e o Codex já gravam na sua máquina. Não há conta, servidor nem telemetria.

IDE leve

Workspaces em abas, explorador com cores do Git em tempo real, editor Monaco com abas e divisão de quadros. Tudo volta como estava ao abrir.

Terminais em grade

De 1 a 4 colunas, com abas, renomear e arrastar. PowerShell, Git Bash, CMD, zsh, bash, fish e WSL. Cole prints direto na CLI.

US$

Custo por token

Tokens × preço por 1 milhão, com cache de 5 minutos e de 1 hora cobrados separadamente, modo rápido e buscas web. Cada resposta contada uma vez.

5h

Limites do plano

Limite de 5 horas e semanal do Claude Code sempre à vista, lidos da statusline, sem usar a sua senha. Limites do Codex também.

RTK

Menos tokens

Integração com o RTK, que filtra a saída dos comandos antes de ela chegar ao agente, no Claude Code e no Codex.

Instalação

Baixe o instalador

Escolha o seu sistema. O instalador já traz tudo o que o app precisa e se atualiza sozinho: o botão Nova versão aparece na barra lateral quando sai uma versão nova. Na primeira abertura, o app oferece instalar o que faltar: Git Bash, RTK e, no Windows, o WSL.

Windows

Windows 10 ou 11, 64 bits.

Baixar para Windows

Cada atualização baixa o instalador completo, sem ação sua.

macOS

Escolha pelo chip do seu Mac (menu Apple > Sobre este Mac).

Apple Silicon (M1 ou mais novo) Intel

Linux

Distribuições 64 bits.

AppImage .deb (Debian e Ubuntu)

O AppImage e o .deb se atualizam sozinhos. No .deb, o sistema pede a sua senha para instalar a versão nova.

Aviso do Windows (SmartScreen)

O instalador do Windows ainda não tem assinatura digital paga, por isso o Windows mostra a tela "O Windows protegeu o computador" na primeira execução de cada versão. O aplicativo é o mesmo que está no GitHub, e a atualização automática confere a integridade do arquivo baixado pelo código de verificação (sha512) publicado junto da versão.

  1. Na tela do aviso, clique em Mais informações.
  2. Clique em Executar assim mesmo.

Ou instale pelo código

Para quem quer o código-fonte. Pré-requisitos: Node.js 22.12 ou mais recente e Git. Cada jeito se atualiza pelo próprio caminho, e os dois usam a mesma pasta de dados do usuário (configurações, workspaces e preços), então não instale os dois ao mesmo tempo.

Instalar

git clone https://github.com/bsmagalhaes/rendra-ui-ide cd rendra-ui-ide npm install npm start

Atualizar

O app avisa quando sai uma versão nova: clique no botão verde Nova versão na barra lateral. Na primeira abertura depois de atualizar, um modal de Novidades mostra o que mudou e só fecha pelo botão Fechar. Pelo terminal, o equivalente é:

git pull npm install npm start
Perguntas frequentes

Dúvidas comuns

O Rendra IDE é open source?

Sim. Código aberto sob a licença MIT, sem conta e sem telemetria.

O custo mostrado é o que eu pago?

Não necessariamente. É o custo equivalente pelo preço de tabela da API (tokens × preço por 1 milhão). Em planos por assinatura, serve para comparar projetos e modelos e ver onde o consumo está, não como fatura.

Preciso ter o Claude Code ou o Codex instalados?

Não. A IDE e a página Terminal funcionam sozinhas. As páginas de consumo aparecem preenchidas assim que houver sessões dessas CLIs na máquina.

O Windows mostrou um aviso azul ao instalar. É seguro?

É o SmartScreen, que avisa sobre instaladores sem assinatura digital paga. Clique em Mais informações e depois em Executar assim mesmo. O código é aberto (MIT) e o instalador é gerado pelo GitHub a partir dele.

Funciona no macOS e no Linux?

Sim. Os terminais se adaptam ao sistema: zsh, bash e fish no macOS e Linux; PowerShell, Git Bash, CMD e WSL no Windows. Há instalador para Windows, macOS e Linux.

Como o app lê os limites do plano sem a minha senha?

O Claude Code envia os limites de uso ao comando da statusline. O Rendra IDE registra esses dados num arquivo local e repassa tudo para a statusline que você já usava.
